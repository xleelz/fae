# Task retirement

`fae retire --task ID --reason 'superseded-by SUCCESSOR'|'contained SHA'|'obsolete RULING' --authorizing-message MESSAGE` uses its own `Retire` RPC and the audited task-control boundary. Retirement time is taken from the daemon clock and recorded on committed events/audit. Only Escalated tasks without an unresolved dispatch may retire; terminal tasks cannot restart or re-enter readiness.

Supersession requires another existing task and atomically replaces outgoing blocking edges with successor edges, following already-retired supersession chains (at most 1,000 identities), deduplicating existing edges and validating the resulting graph before commit. An introduced self-edge or cycle refuses the whole operation. A chain ending at contained releases; one ending at obsolete holds. Supersession cycles fail closed. Related edges retain their meaning. Containment releases blocking dependents; obsolescence keeps them held and reports a dead prerequisite. The task snapshot, backlog mirror (when present), dependency changes, typed retirement event and authorization consumption commit in one SQL transaction. Lost acknowledgements use the existing exact snapshot-version recovery boundary.

Containment requires an exact resolving commit SHA from the task's own validated live broker commit receipt or live integration artifact. A branch tip, abbreviated SHA, symbolic ref or ancestry relationship alone is never evidence. Subject-only discovery of an integration commit without a retained task artifact is not yet implemented and fails closed. Supersession validates successor identity and graph safety; semantic acceptance coverage remains an operator judgment.

Status totals, board, history, events and backlog topology hide retired tasks by default; `--include-retired` (RPC `include_retired`) opts in. Backlog reads retain an anonymized dead-prerequisite hold so hidden retirements cannot make dependents appear ready. Event queries filter before limiting, so hidden rows cannot starve later visible events; streaming accepts `include_retired=true`. Stored events and snapshots are never deleted by retirement. The cached status keeps all rows and derives visibility per request.

Tests cover engine legality, malformed reasons, active dispatch refusal, terminal immutability, real Git object containment/foreign ancestry refusal, native Dolt atomic graph transfer and duplicate edges, cycle refusal without version change, obsolescence, retired read filtering and daemon restart. Gobra verifies the production containment guard; Gomela checks transfer acknowledgement before retirement publication with a deliberately broken negative model.
