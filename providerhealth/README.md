# Provider observations and routing

`ReadLog(io.Reader)` is the single JSONL diagnostic parser. It reads at most 1 MiB, recognizes only structured error events, and ignores ordinary message/work payloads and plain terminal text. `SessionLogs(directory)` discovers `events.jsonl` at the launch directory or within its `provider-*` children. Direct creates a fresh private directory at launch and the Codex bridge captures its CLI's JSON event stream there; no global session directory or terminal scraping is used. Files and child directories cannot be symlinks. Unknown error events classify as model-api-error. `Classify(directory, validOutput, timedOut)` supplies the success/timeout/malformed fallback and is shared with missing-handoff diagnostics.

A genuine structured error observation still affects health if the provider subsequently supplies a valid handoff. Error-looking words inside a valid payload never affect health. The event stream is bounded at its producer and consumer. A CLI without a trusted structured event adapter cannot safely infer provider errors from free text; its missing output falls back to malformed-output.

Scores start at 100, decay toward 100 with a one-hour half-life, and use the specified penalties. Eligibility is at least 50. Successful observations restore 100 outside the one-hour throttle hold; inside the hold only elapsed-time healing applies. Health is keyed by provider/model, independent of effort.

The SQL `ObserveProvider` transaction serializes updates, stores an idempotent observation keyed by session, and writes the health row, durable operator audit line, and event together. Repeated identical observations do nothing; conflicting repeats refuse. The audit row is the durable log rather than an external append-only file, whose crash-time exactly-once semantics cannot be guaranteed. API readers expose observations and effective health.

`PrepareWithRoutes` selects each role's first eligible route before charging an attempt. All unavailable routes park without changing the attempt/visit/sequence counters. The daemon rechecks every five seconds and on ordinary wakeups. The exact selected binding is checkpointed in each Session and later copied to artifact provenance. Health never rewrites an in-flight binding or past evidence. Launched failures continue to park uncertain; selection of a fallback for subsequent dispatches does not authorize replay of possible effects.

A typed infrastructure admission refusal is retryable without charging an attempt only before any session in that dispatch launches. A partial multi-review dispatch parks uncertain. Deferral keeps dispatch sequence numbers monotonic and rolls back exactly its charged attempt and stage visit. Readiness retries, CPU-based stalls, and persistent provider sessions remain separate work.
